Замеры выполнены на MacBook Pro с Apple M5 Pro, в сборке Release.
Для каждого размера создавался один массив случайных чисел. Каждая сортировка получала его копию, поэтому исходные данные были одинаковыми. Время копирования в замер не входило.

Каждая сортировка запускалась один раз. Время в таблице указано в миллисекундах.

| Сортировка | 10 000 элементов | 100 000 элементов |
|---|---:|---:|
| Пузырёк классический | 26.369 | 3253.940 |
| Пузырёк с выходом без обменов | 24.998 | 3141.110 |
| Пузырёк с границей последнего обмена | 23.321 | 3101.780 |
| Шейкерная | 23.991 | 4032.170 |
| Шейкерная с оптимизацией правой границы | 24.755 | 3821.910 |
| Чёт-нечет | 22.212 | 2676.030 |
| Расчёска | 0.355 | 4.265 |
| Выбором | 75.861 | 4681.040 |
| Вставками классическая | 6.323 | 604.037 |
| Вставками с бинарным поиском | 1.310 | 141.373 |
| Шелла | 0.511 | 6.625 |

Быстрее всего на обоих размерах сработала расчёска, следом - сортировка Шелла. Самой медленной оказалась сортировка выбором.

Бинарный поиск заметно ускорил сортировку вставками. У пузырьковых и шейкерных сортировок оптимизации дали небольшую разницу: на 100 000 элементах они всё равно работали несколько секунд.
